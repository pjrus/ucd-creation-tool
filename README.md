# UCD Studio

UCD Studio is a local-first UML use case diagram editor driven by readable, Markdown-like source.

## Development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run check
npm run lint
npm run typecheck
npm run build
```

The app uses TanStack Start and Router, React, TypeScript, Tailwind CSS, and shadcn/ui.
